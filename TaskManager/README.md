# TaskManager – Ứng dụng Flutter

Thư mục này chứa **`lib/`** và **`pubspec.yaml`**. Các thư mục nền tảng (`android/`, `ios/`…) do lệnh `flutter create` sinh ra – xem `HUONG_DAN.md` ở thư mục gốc, mục 3.

Địa chỉ API nằm ở `lib/utils/constants.dart`:
- Máy ảo Android: tự dùng `http://10.0.2.2:3000/api`
- Điện thoại thật: điền IP máy tính vào `lanHost`
